## Download

| Your computer | File |
| --- | --- |
| Windows 10 or 11 | `TopicModelTool-Setup-<version>.exe` |
| Mac with Apple silicon (M1 or newer) | `TopicModelTool-<version>-macOS-arm64.dmg` |
| Theme naming (optional, about 4.9 GB, download every part) | `naming-model-llama3.1-8b.tmtpack.001`, `.002`, `.003` and `naming-model-llama3.1-8b-LICENSE.txt` |

Not sure which Mac you have? Apple menu → About This Mac. "Chip: Apple M…" means Apple silicon.

**First time opening it?** Windows and macOS show a warning because this free app isn't sold through an app store. See [How to open the first time](docs/FIRST_OPEN.md).

Everything works offline after install. Your documents never leave your computer.

Checksums for every file are in `SHA256SUMS.txt`.
